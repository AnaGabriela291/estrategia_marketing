## Ver en línea (Vercel)

Es un sitio estático: no necesita instalar nada ni compilar.

| Ruta | Página |
|---|---|
| `/` | Portada con enlaces a los dos documentos (`index.html`) |
| `/estrategia` | Sistema de ventas ANAINNOVA |
| `/sistema-3x30` | Sistema 3×30 aplicado a ANAINNOVA |
| `/palabras-clave` | Palabras clave, regalos y mensajes de ManyChat |
| `/regalos/web`, `/regalos/precio`… | Regalos que se envían por mensaje privado |
| `/analisis` | Análisis de Víctor Heras |

Para publicarlo:

1. Entra a [vercel.com/new](https://vercel.com/new) e inicia sesión con GitHub.
2. Importa el repositorio `AnaGabriela291/estrategia_marketing`.
3. Deja **Framework Preset: Other**, sin comando de build y con el directorio raíz por defecto.
4. Pulsa **Deploy**.

Cada vez que subas cambios a la rama `main`, Vercel vuelve a publicar solo.

Las páginas llevan `noindex` para que Google no las muestre en búsquedas. Si prefieres que sea privado del todo, activa **Deployment Protection** en la configuración del proyecto en Vercel.

También puedes abrir los archivos `.html` directamente en el navegador.
